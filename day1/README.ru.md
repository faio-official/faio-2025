Добро пожаловать на День 1 олимпиады. Сегодняшние три задачи дают вам табличные признаки изображений, задачу вопрос–ответ и аудио — и просят извлечь из каждого структуру. Решать можно в любом порядке; каждая задача оценивается отдельно. Удачи.

- **1 — Казахские буквы.** Классифицируйте каждую казахскую букву по набору рукотворных числовых признаков, извлечённых из её изображения (42 класса).
- **2 — Кто самый лучший питчер?** Постройте агента с дополненной выборкой (RAG), который отвечает на вопросы о Главной лиге бейсбола (MLB) по структурированным JSON-данным, совпадая с ответом в точности.
- **3 — Потерянная нота.** Определите исходную музыкальную ноту по аудиоклипу, из которого удалена основная частота.

**Решать:** [contest.faio.kz](https://contest.faio.kz)

**Изначально проходил на:** Kaggle *(старая ссылка)*
