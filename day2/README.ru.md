Добро пожаловать на День 2. Сегодняшние две задачи переходят к рекомендациям и поиску изображений. Решать можно в любом порядке; каждая задача оценивается отдельно. Удачи.

- **1 — HearMe: персональный музыкальный рекомендатель.** Порекомендуйте 50 самых релевантных треков для каждого слушателя; ваша оценка отражает, какую долю рекомендаций он действительно прослушает.
- **2 — Заблудившиеся в музее.** Постройте эмбеддинг для каждого изображения так, чтобы фотография посетителя находила соответствующую высококачественную музейную картину среди трёх лучших кандидатов.
