Условие задачи

Правильный ответ в этой задаче дает 10 баллов.

Существует редкое заболевание, которым болеет 1% населения.

Для диагностики этого заболевания разработан новый тест, который работает следующим образом:

  • Если человек действительно болен, тест покажет положительный результат в 99% случаев.

  • Если человек здоров, тест покажет отрицательный результат в 98% случаев.

Теория

Вероятность

Интуитивно Вероятность — это число от 0 до 1, показывающее, насколько «ожидаемо» событие:
0 — невозможно, 1 — случится обязательно, середина — «может быть» с тем или иным шансом.

Формально Вероятность события A A A — это значение вероятностной меры P ( A ) P(A) P(A) (функция, которая событиям приписывает число от 0 до 1), причём: 0 ≤ P ( A ) ≤ 1 , P ( Ω ) = 1 , P ( ∅ ) = 0 , 0 \leq P(A) \leq 1,\quad P(\Omega)=1,\quad P(\varnothing)=0, 0≤P(A)≤1,P(Ω)=1,P(∅)=0, где Ω \Omega Ω — всё возможное, ∅ \varnothing ∅ — невозможное событие. При равновозможных исходах: P ( A ) = число благоприятных исходов общее число исходов . P(A) = \frac{\text{число благоприятных исходов}}{\text{общее число исходов}}. P(A)=общее число исходовчисло благоприятных исходов​.

Применение

  • Data analysis: доля пользователей, совершивших покупку, интерпретируется как оценка P ( покупка ) P(\text{покупка}) P(покупка).

  • ML: выход модели-классификатора (например, 0.83) трактуется как оценка P ( класс = 1 ∣ признаки ) P(\text{класс}=1 \mid \text{признаки}) P(класс=1∣признаки).

Условная вероятность

Интуитивно Это «вероятность внутри фильтра»: уже известно, что произошло B B B, и интересует шанс A A A среди таких случаев, а не среди всех.

Официально Условная вероятность A A A при B B B определяется как: P ( A ∣ B ) = P ( A ∩ B ) P ( B ) , P ( B ) > 0 , P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0, P(A∣B)=P(B)P(A∩B)​,P(B)>0, где A ∩ B A \cap B A∩B — «оба события одновременно».

Применение

  • Data analysis: конверсия сегмента = P ( конверсия ∣ канал = соцсети ) = P(\text{конверсия} \mid \text{канал}=\text{соцсети}) =P(конверсия∣канал=соцсети).

  • ML: чувствительность по классу k = P ( верный прогноз ∣ класс = k ) k = P(\text{верный прогноз} \mid \text{класс}=k) k=P(верный прогноз∣класс=k).

Теорема Байеса

Интуитивно Помогает «перевернуть» условную вероятность: из «насколько часто B B B случается, если верна причина A A A» получить «насколько вероятна причина A A A, когда увидели B B B», с учётом стартовой уверенности (априори).

Официально Формула Байеса: P ( A ∣ B ) = P ( B ∣ A ) ⋅ P ( A ) P ( B ) , P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)}, P(A∣B)=P(B)P(B∣A)⋅P(A)​, где P ( A ) P(A) P(A) — априорная вероятность (стартовая оценка A A A), P ( B ∣ A ) P(B \mid A) P(B∣A) — правдоподобие (насколько типично B B B при A A A), P ( A ∣ B ) P(A \mid B) P(A∣B) — апостериорная вероятность (обновлённая оценка A A A после факта B B B).

Применение

  • Data analysis: корректная интерпретация положительного теста при редком событии (учёт базовой распространённости P ( A ) P(A) P(A)).

  • ML: наивный Байес — вычисление P ( класс ∣ признаки ) P(\text{класс} \mid \text{признаки}) P(класс∣признаки) через P ( признаки ∣ класс ) ⋅ P ( класс ) P(\text{признаки} \mid \text{класс}) \cdot P(\text{класс}) P(признаки∣класс)⋅P(класс) и нормировку по P ( признаки ) P(\text{признаки}) P(признаки).

Формат ответа

Случайно выбранный человек из населения сдал тест, и его результат оказался положительным.

Какова вероятность того, что этот человек действительно болен? Ответ округлите до четырех знаков после запятой.

Ответ нужно представить в виде десятичной дроби с четырьмя знаками после точки, например, 0.3147.
