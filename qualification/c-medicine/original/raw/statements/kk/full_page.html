Есептің шарты

Бұл есептің дұрыс жауабы 10 ұпай береді.

Халықтың 1%-ы шалдыққан сирек кездесетін ауру бар.

Бұл ауруды диагностикалау үшін келесідей жұмыс істейтін жаңа тест әзірленді:

  • Егер адам шынымен ауырып қалса, тест 99% жағдайда оң нәтиже көрсетеді.

  • Егер адам сау болса, тест 98% жағдайда теріс нәтиже көрсетеді.

Теория

Ықтималдық

Қарапайым тілмен Ықтималдық — бұл оқиғаның қаншалықты «күтілетінін» көрсететін 0-ден 1-ге дейінгі сан:
0 — мүмкін емес, 1 — міндетті түрде орындалады, ортасы — белгілі бір мүмкіндікпен «болуы мүмкін».

Формалды түрде A A A оқиғасының ықтималдығы — бұл P ( A ) P(A) P(A) ықтималдық өлшемінің мәні (оқиғаларға 0-ден 1-ге дейінгі санды тағайындайтын функция), және: 0 ≤ P ( A ) ≤ 1 , P ( Ω ) = 1 , P ( ∅ ) = 0 , 0 \leq P(A) \leq 1,\quad P(\Omega)=1,\quad P(\varnothing)=0, 0≤P(A)≤1,P(Ω)=1,P(∅)=0, мұндағы Ω \Omega Ω — барлық мүмкін оқиғалар кеңістігі, ∅ \varnothing ∅ — мүмкін емес оқиға. Тең мүмкіндікті нәтижелер үшін: P ( A ) = қолайлы нәтижелер саны барлық нәтижелер саны . P(A) = \frac{\text{қолайлы нәтижелер саны}}{\text{барлық нәтижелер саны}}. P(A)=барлық нәтижелер санықолайлы нәтижелер саны​.

Шартты ықтималдық

Қарапайым тілмен Бұл «сүзгі ішіндегі ықтималдық»: B B B оқиғасының орындалғаны белгілі, бізді барлық жағдайлардың арасында емес, тек осындай жағдайлардың ішіндегі A A A-ның мүмкіндігі қызықтырады.

Формалды түрде B B B оқиғасы орындалғандағы A A A-ның шартты ықтималдығы келесідей анықталады: P ( A ∣ B ) = P ( A ∩ B ) P ( B ) , P ( B ) > 0 , P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0, P(A∣B)=P(B)P(A∩B)​,P(B)>0, мұндағы A ∩ B A \cap B A∩B — «екі оқиғаның бір мезгілде орындалуы».

Қолданылуы

  • Data analysis: сегмент конверсиясы = P ( конверсия ∣ арна = әлеуметтік желі ) = P(\text{конверсия} \mid \text{арна}=\text{әлеуметтік желі}) =P(конверсия∣арна=әлеуметтік желі).

  • ML: k k k класы бойынша сезімталдық = P ( дұрыс болжам ∣ класс = k ) = P(\text{дұрыс болжам} \mid \text{класс}=k) =P(дұрыс болжам∣класс=k).

Байес теоремасы

Қарапайым тілмен Шартты ықтималдықты «аударуға» көмектеседі: «егер A A A себебі орындалса, B B B қаншалықты жиі кездеседі» дегеннен, бастапқы сенімділікті (априорлы) ескере отырып, « B B B оқиғасын байқағанда, A A A себебінің ықтималдығы қандай» дегенді алуға болады.

Формалды түрде Байес формуласы: P ( A ∣ B ) = P ( B ∣ A ) ⋅ P ( A ) P ( B ) , P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)}, P(A∣B)=P(B)P(B∣A)⋅P(A)​, мұндағы P ( A ) P(A) P(A) — априорлы ықтималдық ( A A A-ның бастапқы бағасы), P ( B ∣ A ) P(B \mid A) P(B∣A) — шындыққа жанасымдылық ( A A A орындалғанда B B B-ның қаншалықты типтік екені), P ( A ∣ B ) P(A \mid B) P(A∣B) — апостериорлы ықтималдық ( B B B оқиғасынан кейінгі A A A-ның жаңартылған бағасы).

Қолданылуы

  • Data analysis: сирек оқиға кезінде оң тестті дұрыс түсіндіру (базалық таралуы P ( A ) P(A) P(A) ескеріледі).

  • ML: қарапайым Байес — P ( класс ∣ белгілер ) P(\text{класс} \mid \text{белгілер}) P(класс∣белгілер) есептеуі P ( белгілер ∣ класс ) ⋅ P ( класс ) P(\text{белгілер} \mid \text{класс}) \cdot P(\text{класс}) P(белгілер∣класс)⋅P(класс) арқылы және P ( белгілер ) P(\text{белгілер}) P(белгілер) бойынша нормалау.

Жауап форматы

Халық арасынан кездейсоқ таңдалған адам тест тапсырды, және оның нәтижесі оң болды.

Бұл адамның шынымен ауырып қалған ықтималдығы қандай? Жауапты үтірден кейін төрт таңбаға дейін дөңгелектеңіз.

Жауапты нүктеден кейін төрт таңбасы бар ондық бөлшек түрінде ұсыну керек, мысалы, 0.3147.
