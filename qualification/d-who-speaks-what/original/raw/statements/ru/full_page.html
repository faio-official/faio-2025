Кто о чём говорит?

Предыстория

Два стажера, Адильхан и Дархан, только что начали работать data scientist’ами в NLP-команде крупной телекоммуникационной компании. Тимлид предложил им первое задание: улучшить чат-бота службы поддержки компании.

Поскольку у телекома миллионы клиентов, говорящих на казахском, русском и английском языках, ключевым требованием является точное определение языка клиента с самого первого запроса. Без правильного распознавания языка чат-бот может ответить не на том языке, что разочарует пользователя.

Чтобы решить эту проблему, Адильхан и Дархан собрали датасет из реальных диалоговых сообщений службы поддержки компании. Они подготовили два файла: train.csv и test.csv, каждый из которых содержит короткие тексты с метками одного из трех языков: ‘‘ru’’, ‘‘kaz’’ или ‘‘eng’’.

Теперь ваша миссия — построить модель, которая сможет точно определять язык любого входящего текста. Ваша помощь жизненно необходима: если Адильхан и Дархан справятся с задачей, они пройдут стажировку и станут штатными NLP-инженерами!

Формальная постановка задачи

Вам даны два CSV-файла:

  • train.csv: Содержит обучающие данные в виде примеров текста с соответствующими метками (ru, kaz, eng).

  • test.csv: Содержит только примеры текста без меток. Ваша модель должна предсказать правильную метку для каждого тестового примера.

Доступ к датасету можно получить по ссылкам:

  • Обучающий датасет (Train)

  • Тестовый датасет (Test)

Входные данные

  • train.csv со столбцами: text, label.

  • test.csv со столбцом: text.

  • Метки принимают одно из значений: ru, kaz, eng.

Выходные данные

Участники должны отправить только CSV-файл с именем solution.csv со следующим форматом:

id,label
0,eng
1,kaz
2,ru
...

Важно: Отправляйте только файл solution.csv. Исходный код не требуется. Порядок значений id в файле solution.csv должен строго соответствовать порядку в файле test.csv, начиная с 0 и до наивысшего ID.

Оценка решения

  • Ваши предсказания будут оцениваться с использованием метрики Macro F1-score.

  • Финальный балл соревнования нормируется следующим образом:

    • Если F1-score < 0.6 < 0.6 <0.6: балл = 0.

    • Если F1-score = 1.0 = 1.0 =1.0: балл = 100.
