## Введение

**Адильхан** и **Дархан** — молодые исследователи, которые решили изучить, как технологии могут улучшить физические тренировки. Они предоставили участникам **IMU-сенсоры** и записали несколько повторений упражнений из йоги. Каждая попытка была размечена как `правильная` или `неправильная`.

Их цель проста: обучить модель, которая автоматически определяет, было ли повторение выполнено правильно. Теперь ваша задача — продолжить их работу и построить точный классификатор для оценки новых повторений йоги.

## Формулировка задачи

Вам даны три CSV-файла:

- `X_train.csv`: обучающая выборка с сегментами данных IMU.
- `y_train.csv`: метки для обучающей выборки (`0` = неправильно, `1` = правильно).
- `X_test.csv`: тестовая выборка с сегментами IMU-данных, без меток. Ваша модель должна предсказать метку для каждого примера из теста.

Все три файла находятся в `data.zip` (см. раздел **Данные** ниже).

## Входные данные

### Признаки (X)

Каждое повторение представлено временным рядом показаний IMU с частотой **200 Гц**. Предоставлены следующие сигналы датчиков:

- `ax`, `ay`, `az` — линейное ускорение (g) вдоль осей X, Y, Z.
- `wx`, `wy`, `wz` — угловая скорость (град/с) вокруг осей X, Y, Z.

### Метки (y)

- `0` — повторение выполнено неправильно.
- `1` — повторение выполнено правильно.

Каждый `id` соответствует одному повторению йоги.

## Выходные данные

Участники должны отправить только CSV-файл под названием **solution.csv** следующего формата:

```
id,label
0,1
1,0
2,1
...
```

**Важно:** отправляйте только файл `solution.csv`. Исходный код предоставлять не требуется. Порядок значений в поле `id` в файле `solution.csv` должен строго соответствовать порядку в файле `test.csv`, начиная с `0` и до наибольшего ID.

## Оценивание

- Ваши предсказания будут оцениваться по метрике **Accuracy**.

## Пример

**Вход (`X_test.csv`):**

```
id,ax,ay,az,wx,wy,wz
0,0.12,0.04,0.98,-1.2,0.3,0.1
1,0.01,0.15,1.02,0.8,-0.5,0.0
2,-0.10,0.20,0.95,0.7,0.1,-0.2
```

**Ваш вывод (`solution.csv`):**

```
id,label
0,1
1,0
2,1
```
